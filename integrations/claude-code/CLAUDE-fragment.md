## Decyzje (pdi)
- Zanim zaproponujesz rozwiązanie w obszarze, który mógł być już rozstrzygnięty, sprawdź `find_decisions` (pdi) —
  najpierw z filtrem `project` = nazwa bieżącego repo, potem bez filtra.
  Gdy propozycja przeczy wcześniejszej decyzji, powiedz to wprost, podaj jej ID i zaproponuj `supersede_decision`
  zamiast cichej zmiany kursu.
- Decyzje zapisujesz tylko na prośbę człowieka (`/record-decision`), po zatwierdzeniu szkicu.
